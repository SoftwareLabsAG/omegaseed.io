Changelog

VERSION HISTORY · CURRENT 1.3.1

How versions are numbered. The scheme is MAJOR.MINOR.PATCH:

  • MAJOR — the conversion or the character set changes. A plate loaded with an earlier major version can then no longer be recalculated identically. Such changes are highlighted separately.
  • MINOR — new functions or new content, calculation unchanged.
  • PATCH — bug fixes, wording and presentation changes.

Checksum of the offline file. Exactly one offline file with a fixed SHA-256 checksum belongs to each published version. The current one is shown in the offline section and in SHA256SUMS.txt. Machine-readable: version.json.

Version 1.3.1

09.09.2026 Release

The signatures are now on the page.

  • The verify the signature section shows the values in plain text: checksum, the full Ed25519 signature and the checksum of the ML-DSA signature — for both offline files. Nothing needs to be downloaded to see what you are checking against.
  • Direct links to release v1.2.0 and to the individual signature files on GitHub.
  • The ML-DSA key was replaced because its password was no longer available. The version 1.2.0 signatures were re-created with the new key; the files themselves were left untouched, which the unchanged Ed25519 signatures prove. The previous public key remains published for the record.
  • Package and signature are published separately. The delivery package lives under SoftwareLabsAG, the checksum list and both signatures under Omega-Secure. For the question of which version is the newest, the server follows the signature side.
  • The offline files are still unchanged from 1.2.0. Their checksums remain valid.

Version 1.3.0

08.09.2026 Release

Signatures explained on the website.

  • New section in the offline area: how to check a downloaded file against the published signatures, linking to the releases and to the separate key repository.
  • Both public keys are served directly from the website (omegaseed.pub, omegaseed-mldsa.pub) so they can be compared from two independent sources.
  • Clarified that a checksum on the same page as the file proves nothing — only a signature against a key published elsewhere does.
  • The offline files are unchanged from 1.2.0. Their checksums and signatures remain valid; anyone who has already verified them need not do so again.

Version 1.2.0

15.08.2026 Release

One navigation for every screen.

  • Menu structure as on omdp39.io: a flat header with the wordmark centred and a round button on the left that opens the menu as a card. This now applies at every width — the site has one navigation instead of two.
  • The menu holds the sections of the tool, all legal pages, the appearance (light or dark), the language choice and the version number. Legal notice, privacy policy, terms of use and changelog are therefore reachable from every page, on the phone as well.
  • The menu button hangs freely below the bar at the left edge of the screen, as in the reference. It sits outside the header technically, because the header's backdrop filter would otherwise establish its own containing block and fixed positioning would have no effect.
  • The current section is tracked in the menu while scrolling.
  • Spacing straightened out: hero, sections, footer and the menu button all sit on one edge. The hero used to sit 24 pixels further left than everything below it.

Version 1.0.1

14.08.2026 Release

Notations R and Q reconciled.

  • R and Q denote the same character (value 23). OMDP39 writes an R there, the tiles carry a Q.
  • Codes containing R are now accepted and mapped automatically to Q for loading; the number of characters converted is displayed.
  • Explanatory box in the encoding section, R highlighted in the alphabet.
  • The 33-word calculator shows both notations side by side.
  • Additional notes for sorting, labelling and verifying.

First public release.

  • Versioning and this changelog introduced.
  • Website split into individual pages, fonts and word list as separate files.

The OmegaSeedphrase is a hardware product made of metal. omegaseed.io is the free companion loading aid for it. All calculations run locally in your browser. No cookies, no tracking, no external resources, no storage of your input.
